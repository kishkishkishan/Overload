# Overload

A gym log that installs to the iPhone Home Screen and works offline.

- Programme with a daily check-in that builds the session
- Machine swaps: rule out busy or missing kit and get the closest substitute
- Last-session targets, muscle heatmap, cardio, sauna, weigh-ins, progress photos

All workout data stays on the phone (IndexedDB). This repository holds only the app code.

Install: open the GitHub Pages link in Safari, tap Share, then Add to Home Screen.
